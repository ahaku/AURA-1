Shortcuts

While the panel has focus:

  • White keys 1–8: Q–I, 9–16: A–K. Black keys 1–11: 1–0, -.
  • C SEL (Solo Mode), P PLAY, O REC (freeze), V ENV (Pad), Esc HOME, N EDIT (Esc+N Random World), Z / X OCT− / OCT+.
  • ↑ ↓ turn SELECT. Shift+Esc Zen mode.

Controls

Each control has an invisible button over it for the keyboard and a screen reader. Tab moves naturally between them without trapping focus; Space or Enter presses a button or key; Shift+Enter latches it. Arrow keys turn a knob, Page Up and Page Down faster.
